# Changelog

What changes for an app built on Ely, newest first. An entry names the crates it touches. Versions follow semver: below 1.0, a breaking change raises the minor version, and CI's `semver` job fails one that does not.

## Unreleased
- `ely-canvas` 0.4.0: native content colors override theme slots without losing alpha; separate fill/image opacity, seeded solid/hachure/cross-hatch/zigzag fills and left/center/right text alignment render natively. Inspector retains eight-color palettes and clears exact overrides when a slot is chosen; fill styles and text alignment reuse Ely controls.
- `ely-editor`: `SyntaxSnapshot`, `SyntaxToken` and stamp-checked `CodeEditor::set_syntax` accept asynchronous local parser projections for themed byte-range highlighting, outlines, structural folds, bracket matching and newline indentation. Parser-owned syntax never falls back to a lexical scan while a newer text is pending; publishing results preserves IME, selections and undo history.
- `ely-editor`: parser folds and bracket tables are prepared once at publication and shared by paint frames and movement; no per-frame full-table cloning or conversion.
- `ely-editor`: newline preserves the current line's indentation and handles newly typed openers before asynchronous syntax arrives; fresh syntax suppresses openers inside strings and comments.
- `ely-editor`: `CompletionMenu` fits its candidate rows and measured label width until the compact maximum viewport is reached; overflow retains Ely two-axis scrollbars. Selection changes reveal the selected row without resetting manual scrolling. `max_width` and `max_height` also cap the viewport to the host's available space.
- `ely-editor`: `CodeEditor::caret_bounds` exposes the same drawn caret geometry used by IME range bounds, so completion hosts can anchor below the true cursor through wide characters, folds, and scrolling.
- GPUI Fast runtime `65bc1fced7a56d91142671c01fea3eaa22cf1024`: destroy app windows and their GPU surfaces before the Wayland platform connection during final teardown, preventing Mesa Vulkan swapchain destruction from dereferencing a disconnected `wl_display`.
- `ely-editor`: per-line syntax colors no longer drop for large sources; a buffer over the `lightweight()` threshold (128 KiB, or a 16 KiB line) kept keywords, types and function names colored while only the whole-buffer fold/bracket scans stayed skipped.
- `ely-canvas`: `MindMap::collapsed` and `on_toggle` provide owner-controlled folded branches over the full topic tree. Localized chevron buttons fold without selecting, activating or editing, including read-only maps; layout, connectors and keyboard navigation include only visible topics. Folding preserves the viewport, independent search highlights and controlled selection for later expansion. The gallery demonstrates folding.
- `ely-charts`, `ely-canvas`: `NetworkGraph::highlighted` and `MindMap::highlighted` accent multiple matching node indices or topic keys without changing layout, hover, activation or viewport; mind-map selection remains independently outlined. Empty matches restore normal styling and unknown matches are ignored.
- `ely-charts`: `NetworkGraph::on_activate` reports a node's index and name after a non-drag press or keyboard activation; arrow keys walk the focused graph's nodes. Without a callback, graphs retain drag and hover without activation overlays or Tab stops.
- `ely-canvas`: `MindMap::on_activate` reports Enter or a double press on a topic; `read_only` disables editing commands while retaining selection, activation and viewport gestures.
- All workspace crates and the native/web gallery: migrate directly to Fast 0.1.14 packages `gpui-fast`, `gpui-fast-platform` and `gpui-fast-web` from `https://github.com/kangxiaoju/Ely-GPUI-Components.git`, fixed at revision `40427c396cc92b6946940e0e498612a8b680ce30` on `runtime/gpui-fast-0.1.14`, retaining the `gpui`/`gpui_platform`/`gpui_web` dependency keys. Disable platform/web default features, retain native `font-kit`/`wayland`/`x11` and runtime Metal shaders, and preserve the single-threaded web gallery and its font fallback. Ely remains the product's component/theme layer; no Kit dependency or pre compatibility shim is added to the product.
- Independent `compat/kit`: pin Kit `=0.9.1` with `gpui-fast` enabled and keep the compatibility gate on that pin rather than upgrading to the newest Kit. Its workspace-root `[patch.crates-io]` maps all nine Fast packages to Ely's exact runtime git source and revision, preventing registry/git type duplication. Lockfile regeneration, native/web builds and compatibility tests are deferred to the integration owner; no passing migration checks are claimed.
- `ely-devtools` 0.2.0: `JsonViewer::from_tree` and `JsonEditor::prepared` compose host-prepared trees and validation statuses without parsing during render. Both components can `fill` a bounded panel; `JsonEditor::controls` hides built-in formatting actions. Prepared native elements make these builders UI-thread-only (no longer `Send`/`Sync`), a breaking auto-trait change.
- `ely-editor`: minimap highlighting samples at most 512 rows and 120 columns per row while retaining whole-document navigation, bounding redraw work on large files.
- `ely-mail`: `MailList::on_load_more(loading, has_more, handler)` defers one next-page request when its last virtual row is visible, deduplicated per rows version/count without changing selection or scroll. Hosts retain rows during loading and provide explicit retry on failure.
- `ely-project`: `KanbanBoard::fill_height(true)` fills a height-constrained parent, including empty columns, with independently scrolling cards and fixed headers and footers. Focused cards reveal vertically, and drag landing measures follow the scrolled content; the default content-height layout is unchanged.
- `ely-project`: `KanbanColumn::on_load_more` requests a bounded next page when loaded cards leave spare viewport height in full-height mode. Requests are deferred and deduplicated by measured content/viewport heights and loaded count; omit the callback while pending or exhausted, then reattach when ready.
- `ely-canvas`: public `NodeEmphasis` / `NodeEmphasisPath` provide isolated, theme-hue node outlines in view pixels. Running paths move along their geometry below 30fps; hidden/static paths and reduced motion stop the timer. The canvas gallery demonstrates viewport-filtered running and static outlines without changing its retained scene.

- `ely-core`: `TextInput::clear_sensitive` zeroizes owned text and composition/undo/redo snapshots and resets selection/layout. Masked fields retain sensitive-drop handling after reveal; OS, renderer and caller copies are outside this guarantee.

## 2026-10-26: `ely-core` 0.2.0, every other crate 0.1.1

The first release on crates.io.

- 31 library crates: `ely-core` (chapters 1–14, theme, motion, i18n), one crate per vertical chapter from `ely-charts` to `ely-rendering`, `ely-desktop` (tray, Dock badge, Omarchy), and `ely-gpui-component`, which re-exports them all under their chapter names.
- gpui, gpui_platform and gpui_web from `gpui-pre` `=0.3.10`, the snapshot GPUI Kit 0.8.1 pins, so Ely and Kit share a window.
- `ely-core` 0.2.0: gpui_platform moves behind the `platform` feature, off by default, so a Button-only app links no gpui backend Ely chose; `runtime_shaders` turns it on, and `ely-gpui-component` keeps both on. `init` fails on a platform with no text system, naming the features that give one: `font-kit` on macOS, `wayland` and `x11` on Linux.
- Every public item documented, each component with an example that compiles and runs; `api/` holds each crate's public API.
- Every focus stop has a role and a name for screen readers; `gallery --audit` walks them on Windows.
- Messages in English, Chinese, German, French, Japanese and Hebrew; the last four machine translated, awaiting native review.
- Icons link by use and fonts by feature (`fonts`, on by default); fonts embed with `include_bytes!`, and `Combobox::languages` reads Ely's own ISO 639-1 table, so neither `rust-embed` nor `isolang` is a dependency.
